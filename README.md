### This repository is for basic analysis of Fermi Large Array Telescope (Fermi-LAT) data. 

How it works: 
* Choose a "focus" object to look at.
* The script queries the fermi-lat database and gets .fits photon files.
* Makes some basic plots (sometimes the RA and dec parameters of zoomed plots will have to be manually adjusted)

### Python vs JN

This repository currently contains both python files for different types of plotting functions, as well as a Jupyter Notebook that ties it all together. Feel Free to use either one, though the JN is better in my opinion.
